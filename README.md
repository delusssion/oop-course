# OOP course labs

Вариант 4 во всех лабораторных.

| Лаба | Тема | Папка |
|------|------|-------|
| 1 | Основы C++, динамический массив | `lab1` |
| 2 | Класс String, правило пяти | `lab2` |
| 3 | Множество DateSet, перегрузка операторов | `lab3` |
| 4 | Полиморфизм, небесные тела | `lab4` |

Сборка любой лабы:

```
cd labN
cmake -S . -B build
cmake --build build
```
